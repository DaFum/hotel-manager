# Original-parity audit

The release claims functional inspiration only for the twelve terms verified from the
preserved disk material: `STELLEN`, `SERVICE`, `BANK`, `WERBUNG`, `HOTELS`, `PREISE`,
`VERSICHERUNG`, `VERTRAG`, `ZEITUNG`, `RENOV`, `BANKROTT`, and `POOL`.

Their modern counterparts preserve a management decision, a scarce resource or trade-off,
and visible consequences. This audit does not claim copied assets, exact mechanics, or
historical authenticity beyond those terms. Any additional claim remains **unverified**
until supported by durable primary evidence and added through specification review.

## Behavioral review

For each verified term, release review checks that the modern system presents a real
choice and exposes its consequence rather than merely naming a menu. The critical path
and focused domain tests provide automated evidence; this document is
the human-reviewed boundary against unsupported historical claims.

The project is a single-player spiritual successor. It does not copy protected original
graphics, text, code, or assert mechanics that the preserved material does not verify.
